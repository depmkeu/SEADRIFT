# 🌊 SEADRIFT

### Seaweed Drying & Forecasting System

SEADRIFT merupakan sistem berbasis Internet of Things (IoT) yang dirancang untuk membantu proses pengeringan dan pemantauan rumput laut secara lebih terukur.

Sistem ini memanfaatkan sensor untuk memantau kondisi rumput laut selama proses pengeringan dan menyajikan informasi secara digital sehingga pengguna dapat mengetahui kondisi pengeringan dengan lebih mudah.

---

## 🎯 Latar Belakang

Proses pengeringan rumput laut masih banyak dilakukan secara manual dan sangat bergantung pada kondisi cuaca. Hal ini dapat menyebabkan proses pengeringan tidak konsisten dan menyulitkan petani dalam menentukan kapan rumput laut telah mencapai kondisi yang sesuai.

SEADRIFT dikembangkan sebagai solusi untuk membantu melakukan pemantauan kondisi pengeringan secara lebih terukur melalui teknologi IoT.

---

## 💡 Solusi

SEADRIFT mengintegrasikan sensor dan sistem monitoring untuk mengumpulkan data selama proses pengeringan rumput laut.

Data yang diperoleh dapat digunakan untuk memantau:

- 🌡️ Suhu
- 💧 Kelembapan
- ⚖️ Berat/massa rumput laut
- 📊 Perkembangan proses pengeringan

Informasi tersebut kemudian dapat ditampilkan melalui dashboard digital sehingga proses monitoring menjadi lebih mudah.

---

## ⚙️ Teknologi

Project ini menggunakan beberapa teknologi berikut:

- **Internet of Things (IoT)**
- Sensor suhu dan kelembapan
- Load Cell untuk pengukuran massa
- Wi-Fi / konektivitas IoT
- Dashboard monitoring
- HTML untuk halaman web
